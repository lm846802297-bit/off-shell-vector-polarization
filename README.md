# Off-Shell Vector Polarization

Research repository for gauge-invariant spin decomposition of unstable vector resonances and off-shell currents.

The initial research snapshot is developed on `research/initial-theory-snapshot`. It will enter `main` only after pull-request review.

## Governance

- Keep `main` reviewed and reproducible.
- Preserve exact source versions, input hashes, runtime/hardware, parameters, and native outputs.
- Require independent physical validation before promoting a result to established.

## Initial research snapshot

See the topic branch `research/initial-theory-snapshot` for the model definition, Ke-Liu-Mahbub equation-level review, five-point current derivation plan, symbolic checks, numerical regression, and run manifests.
