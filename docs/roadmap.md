# Research roadmap

## Milestone 1 — five-point current constraints

1. Classify local current shifts \(K^\mu\) compatible with the chosen field content and power counting.
2. Derive the complete five-point tree amplitude in the minimal broken SU(2) model.
3. Compute factorization residues in every allowed channel, including Goldstone-sector channels.
4. Determine whether the on-shell recursion fixes the local boundary polynomial.
5. Compare the recursion result with an independent Feynman-rule implementation and the relevant Slavnov–Taylor identity.

## Milestone 2 — complex-pole spin decomposition

1. Introduce the mixed neutral-vector two-point matrix and its complex pole.
2. Derive left/right pole eigenvectors and residue normalization.
3. Construct the spin-1 pole residue in a dual polarization basis.
4. Establish which density-matrix quantities are invariant under gauge-parameter changes and polarization-basis transformations.

## Milestone 3 — non-resonant currents and observables

1. Keep the non-resonant current as a tensor/current object rather than assigning it a fictitious external-particle spin space.
2. Retain pole–regular interference in the full amplitude.
3. Compare the construction with the full off-shell process \(H\to ZZ^*\to4\ell\).
4. Test positivity only for the genuinely pole-defined density matrix, not for an arbitrary off-shell reconstruction.
